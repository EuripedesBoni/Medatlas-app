Ativar contas e sincronização

Assistente local para o responsável pelo aplicativo. Nenhuma informação é enviada por esta página.

1 de 4

Crie o projeto no Supabase

Abra o painel Supabase, crie um projeto no plano Free e configure Authentication → Email com confirmação de e-mail ativada.

Abrir Supabase ↗

Em Authentication → URL Configuration: use como Site URL e Redirect URL https://euripedesboni.github.io/Medatlas-app/.

2 de 4

Crie o banco protegido

Abra SQL Editor no projeto Supabase, copie o SQL abaixo e execute-o. A tabela separa os dados por identificador do estudante usando RLS.

Atenção: teste os filtros por usuário, recuperação e exclusão de conta antes de publicar. O SQL precisa ser executado pelo proprietário do projeto.
3 de 4

Gerar o arquivo de configuração

Em Project Settings → API Keys, pegue a URL do projeto e a chave publishable. Essa chave é pública; a segurança depende da RLS.

Nunca cole aqui: senha, chave service_role, sb_secret_, token pessoal ou senha do banco.

O arquivo gerado contém apenas os dados públicos de conexão. Não forneça sua senha a ninguém.

4 de 4

Validar e publicar

  1. Teste o cadastro e confirmação de e-mail com duas contas de teste diferentes.
  2. Confirme que a conta A não consegue ler nem alterar dados da conta B.
  3. Use a mesma conta em dois dispositivos para testar a sincronização e a resolução de conflitos.
  4. Conclua a política de privacidade com identificação e contato do responsável.
  5. Somente depois envie todos os arquivos da pasta web e o config.js gerado para o GitHub.
